# Recoil Calibration Lab · 配装与截图校准实验室

驱动无关、以证据为输入的离线实验工具。先选择枪械与配件，再用截图、录像或带时间戳的数据测量；不靠武器面板百分比猜鼠标移动量。

仓库：`olu37776-bit/recoil-calibration-lab`。用户建立的公开仓库；不得提交个人截图、录屏、账号信息或驱动凭据。

## V0.3 新增：状态实验室

启动方式不变；首页点击“状态实验室”，或打开 `http://127.0.0.1:8765/state.html`。

- 16种合成场景：空仓、换弹、投掷、背包、近战、腰射、治疗、切姿态、切配装、失焦、过期反馈等。每一步给出停止/放行原因；只记录事件，不操作鼠标。
- 按精确Context选择已有曲线。连射中变化先停止，释放后才能重选；不把站姿乘一个猜测系数当蹲姿。
- 上传两种以上带标签参考图和独立待测图，比较固定HUD区域，返回候选或unknown。没有预装游戏模型，不自动读取弹量，不把候选直接接入回放。
- 雷蛇炼狱蝰蛇标准版的官方基本宏能力已核对，详见 `docs/DEVICE_SUPPORT.md`；品牌驱动未接入，不声称能直接运行卖家的G HUB脚本。

完整实现/未完成边界见 `docs/STATE_FEEDBACK.md`。合成场景不等于真实游戏验收。截图仅处理操作者主动选择的文件；无全局捕获、鼠标注入或随机规避输入。

## V0.4 · 自适应识别

启动后点击顶部“自适应识别”，或打开 `/adaptive.html`。

首次提供至少两种带标签参考图，在第一张参考图框一次稳定HUD图标。可导出参考包保存在本机，下次直接导入。后续待测图自动读取分辨率、尝试多尺度和局部位置匹配；不再要求与参考图同尺寸。界面支持拖动框选，坐标自动换算为原图像素；更换待测图可自动分析。

已有离线连续帧确认接口 `/api/hud-sequence`（2..24帧加明确时间戳）：连续确认后才输出稳定候选，未知立即撤销，分辨率变化重新确认。不是录像自动抽帧或实时屏幕捕获；本页暂不提供序列上传GUI。

合成测试覆盖720p、1080p、1440p、4K及宽屏锚定，不是这些分辨率下WARDOGS实机识别通过。仍需首次参考图；界面样式、语言或游戏版本改变可能需要新模板。没有预训练游戏模型。

**自动定位图标不等于自动缩放压枪力度。** 原始位移、输入响应和曲线仍绑定实际Context。未知、歧义、重复参考图不触发任何鼠标动作。读取图片尺寸不能反推DPI、游戏灵敏度或FOV。

实现与后续自动化路线见 `docs/AUTOMATION.md`，当前状态与验证限制见 `docs/CURRENT.md`。原固定区域状态实验室仍可使用。

## Windows 启动

需要 Python 3.11+ 和 Git。在终端执行：

```powershell
git clone https://github.com/olu37776-bit/recoil-calibration-lab.git
cd recoil-calibration-lab
py -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[ui,test,video]"
.\.venv\Scripts\python -m recoil_lab.ui
```

浏览器打开 `http://127.0.0.1:8765`。不需要先安装鼠标驱动。不要求 PowerShell 激活虚拟环境。端口占用时加 `--port 8766`。

Linux/macOS 使用 `python3 -m venv .venv`，再用 `.venv/bin/python` 执行同样的安装与启动命令。

## 选枪与配装

界面默认从 Galil + 1.5× 瞄具开始，默认数值只是可编辑起点，不是你的已验证设置。左侧选枪，中间选择来源明确列出的兼容配件；右侧填写实际 DPI、灵敏度、瞄准灵敏度、当前倍率、分辨率、FOV、姿态、游戏构建号。

菜单与配装都由同一份服务端目录校验，不能靠修改浏览器 JSON 强行装上未确认兼容的配件。脚架与握把共享下挂槽，不可同时安装。

配件属性按单项展示，**不生成一个假装是实测的“总后坐力 -XX%”**。配装价格仅包含枪、一个弹匣和所选配件；不含弹药和其他装备。弹药包装数量未核验，不换算单发成本。

资料来自独立社区站 `wardogs.tools` 的逐枪页面、配件和进度表，人工核对日期为 **2026-09-23**。网站页脚的 `v1.1.0 / 2026-09-22` 是资料站标签，不能当作实测游戏构建号。没有复制图片或整站文本，没有自动爬虫。详细规则见 `docs/CATALOG.md`。

## 截图怎么用

| 输入 | 能做什么 | 不能做什么 |
|---|---|---|
| 单张原始截图 | 点一次初始瞄准点，再逐个标注弹孔；输出质心偏移、包围盒和 RMS 散布 | 不恢复逐发时间，不推算鼠标 counts，不把标注数等同于射击发数 |
| 射击前 / 射击后两张 | 选择同一静态墙面 ROI，测背景反向总位移并检查追踪质量 | 不当作完整连射曲线，不证明所有位移都来自后坐力 |
| 连续截图 | 显式逐帧时间戳、至少 10 帧、至少 0.2 秒、相邻间隔最多 0.1 秒；通过门禁后导出标准 Trial | 不猜文件名时间、不补帧、不跨失跟踪区间插值 |

支持 PNG、JPEG、WebP；每张最多 6 MiB、1200 万像素。连续序列最多 120 帧、总解码像素 9000 万，HTTP 请求最多 32 MiB。单张模式支持粘贴图片。浏览器中显示时允许缩放，但记录的是**原图像素坐标**。

图像只通过本机环回地址提交给本地分析进程；原始图片不写入仓库、临时目录或远端。用户主动导出的文件由浏览器下载。临时导出目录只保存数值轨迹，并在响应生成后删除。

连续截图导出的元数据与 CSV 一起解压到 `runs/` 后可用于 CLI。相同录屏拆成的多个片段必须使用相同原始录制会话 ID，不能伪装成独立验证。序列目前导入为未补偿训练数据，不是验证回放。

## 原有算法闭环

```powershell
.\.venv\Scripts\python -m recoil_lab demo --out runs/demo
.\.venv\Scripts\python -m recoil_lab --help
```

`response` 从至少两轮无射击的已知输入记录标定像素/输入单位；`fit` 用至少三轮训练数据拟合；`refine` 小步调整；`validate` 使用独立采集会话；`replay` 只导出模拟输入事件。截图序列并不能替代输入响应标定。

录像仍通过 `video` 命令导入。其 `--context` 接收纯 Context JSON；界面导出的配装外层含有 `context` 字段，使用前单独保存该字段。不会隐式把未知鼠标输入当成零，必须声明 `--uncompensated`。

完整单位、数据契约、阶段隔离与拒绝条件见 `docs/CONTRACTS.md` 和 `docs/SCREENSHOTS.md`。

## 验证与状态

```powershell
.\.venv\Scripts\python tools/verify.py
.\.venv\Scripts\python tools/check_evidence.py
```

本次本地自动化测试结果在 `evidence/test-output.txt`、`evidence/verification.json`。测试覆盖合成图像、错误时间戳、配置指纹、配件兼容、API 和原有算法。

浏览器 DOM 冒烟测试的范围在 `evidence/browser-check.json`：容器禁止浏览器导航，故使用无网络 DOM 页面和进程内 API 桥接；真实 HTTP 接口另有测试。**没有声称通过真实浏览器网络端到端、localStorage 持久化、Windows、WARDOGS 或鼠标驱动验收。** GitHub Actions 的结果必须单独查远端，不由本地 PASS 代替。
