# Recoil Calibration Lab · V0.7 日常使用与引导调教

## 先从这三个入口使用

**开始使用**：选择已有配置、核对目标窗口和本次负重；先看识别结果，再明确启用。恢复上次选择不等于自动开始输入。

**调教配置**：只按助手提示做当前步骤。程序保存每轮记录；够一组后自动计算，不自动开始下一轮输入。首次核对本机设置，之后记住；换配件或姿态可复制旧配置，只改所需项。

**教它识别**：选配置并粘贴/导入截图；原始录制编号由程序生成，只有真正重新采集才开启新一批。第一次仍需框选可区分条件的区域，独立检查规则不变。

原5页全部工具仍在“展开全部工具”里；普通使用不必打开技术JSON和原始记录。详细边界见docs/USABILITY.md与docs/CURRENT.md。


**负重现在只是手动选择项。** 在“01 配装与项目”选择未记录、轻装、中装、重装，或输入自定义标签；不自动识别负重，不内置重量后坐系数。

继续原有校准流程后，在同一工作台“05 教识别与自动选档”建立个人识别库：

1. 选择已校准项目，导入实际持枪画面的截图；首次框1至3个能区分配置的图标/提示。后续截图复用位置。
2. 勾选仅本机保存裁剪，填写原始采集会话，把截图加入当前项目参考；为其他枪械/姿态配置追加参考。
3. 另外采集截图作为独立验证：每配置至少2张、每个手动负重标签至少1张未知/应停止状态负例。点击检查识别库。
4. 可以识别一张新图并自动选中项目，也可选择窗口持续“仅识别”。
5. “识别并应用”还要求对应项目的真实补偿曲线通过原有独立RECORDED_REPLAY验证；保持F7+右键+左键使能，F8/Esc急停。未知或切档暂停，释放开火后才重新开始。

**这是真实功能入口，但不是预训练的全游戏识别器。** 程序识别你提供的可见特征，不能从同一个枪名图标读出隐藏配件；画面无法区分的组合会有歧义。首次在获准的受控场景校准和验证，不能把有限样本检查等同于游戏内可靠性保证。源图不上传，只有用户同意的裁剪保存在本机。

当前每库绑定同一原图分辨率和输入环境。原离线分辨率适配实验保留，不把识别像素缩放等同于补偿输入缩放。历史V0.5项目直接保留；复制配装建立新的负重项目，不覆盖旧曲线。

Windows便携包解压整个目录，运行RecoilLab.exe；源码启动仍为 `python -m recoil_lab.app`。详细使用见 `docs/QUICKSTART.md`，本轮规则见 `docs/SELF_TEACHING.md`，验证边界见 `docs/CURRENT.md`。

## 启动

下载当前版本的Windows x64便携包，解压整个目录，双击RecoilLab.exe，不必安装Python。默认打开本机浏览器；控制台关闭即退出。程序未签名，遇到系统拦截保留错误，不关闭安全防护或提权绕过。

源码方式（Python 3.11+）：

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[ui,video]"
.\.venv\Scripts\python -m recoil_lab.app
```

首测可点击“一键跑完整演示”，使用合成数据检查标定、拟合、验证、保存和导出；不能启用实际输入。用户实际项目至少需要2轮响应、3轮训练和3轮独立验证，识别截图不替代补偿曲线的试射记录。

## 配装和参考

内置14把枪、49个配件、18个弹药选项的人工核对社区子集。来源、解锁等级、费用和购买价在目录中展示；未知值不猜。目录见docs/CATALOG.md。面板属性不等于实测补偿。所有枪械与配件选择由后端验证。

负重标签是实验分组，不代表官方档位。脚架展开可单独选择。当前仍要求精确Context，不能把旧响应/曲线自动按分辨率或倍率缩放。

## 识别与执行边界

截图/持枪时能看见的稳定特征才适合做参考；如果图中不显示配件或姿态，不能仅凭枪名宣称已识别全部条件。个人识别库采用灰度区域比较，不依赖OCR，不读取游戏进程，不连接云端。数据默认保存在本机用户目录RecoilCalibrationLab，用户图片不得上传公开仓库。

只有新的个人识别库路径能在独立截图检查和原曲线实测回放检查同时通过后自动选档；旧固定ROI、自适应候选接口仍只做实验。自动模式必须持续监督，F7+右键+左键使能，F8/Esc急停，任务最长120秒；动作/未知/歧义/切档暂停，释放后重启。Ctrl/Shift等仍是保守暂停条件，未承诺所有自定义按键。Windows可能拒绝输入，程序不会绕过。
