# V0.6 自校准与自动选档

基线：c944f62c10e730664fb8645778036a4fbb6b8b8e。用户确认：先手动选条件、截图/试射校准；以后识别并应用保存的配置。负重仅作为手动选项，不做识别，不内置重量后坐力公式。

## 本轮范围
同一工作台增加负重标签、脚架状态、配置复制填表，以及个人识别库：框选1至3个可见特征区域一次，后续截图沿用区域；将截图绑定当前项目。裁剪图只在明确同意后保存本机。完整原图不持久化。

识别库按相同游戏构建、输入设置与窗口尺寸隔离；项目绑定完整Context，负重标签参与精确选择但不直接改变补偿数值。历史项目缺少负重时显示“未记录”，不重写已有指纹/曲线。

识别是用户提供的可见特征分类，不是读取隐藏配件/负重或自动知道所有状态。相同画面对应不同配件会歧义；必须补充能区分的区域，或将候选限制为用户已确认的配装。没有视觉得出的重量值。

## 放行规则
识别与曲线验证分开：参考截图用于教识别；另取独立截图作为识别验证。每个配置至少2张独立验证图、每个负重标签至少1张未知/菜单/换弹等负例。验证图与参考图不能同图或同采集会话；不把人工填写会话ID当来源真实性认证。全部已提交验证图必须通过。新增样本/参考或改变布局使旧识别报告失效。

常规自动选档输出必须同时满足：识别库重新验证通过；匹配精确项目Context；该项目当前曲线通过原有RECORDED_REPLAY验证；用户明确授权、前台窗口/PID/尺寸一致、F7+右键+左键、连续稳定识别。合成项目不能真实输出。单帧预览、原V0.3/V0.4候选仍无输出权限。

本轮只对新的“已教识别库+独立识别检查+原曲线回放检查”组合增加自动选档能力，不放宽原接口。未知/歧义/动作指令立即暂停；换档或恢复先释放开火键，不在同一梭中混合曲线。没有自动扣扳机、无人值守、绕过拦截或检测规避。

自动选档依据1至3个用户框选区域；误识别可能连续存在，有限测试不能证明全游戏识别正确。不可见变化、未提供的未知状态仍需用户监督。负重在启动会话前手动选择，变更先停用。新识别库要求同一原始分辨率；原V0.4离线自适应入口保留，但不隐式迁移鼠标输入标定。

## 验证
旧测试全保留。新增负重校验/历史兼容、持久化裁剪、同图同会话拒绝、未知与相似标签拒绝、识别集变更失效、曲线门禁、连续确认与释放/切换/超时、工作台HTTP与浏览器流程测试。打包、Windows/Linux和浏览器均需新HEAD检查；不称已通过真实游戏/鼠标实测。
