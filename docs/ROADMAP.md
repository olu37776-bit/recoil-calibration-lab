# 路线图

V0.1：离线校准契约、Response、分段Profile、迭代、独立验证、RecordingSink、录像光流。

V0.2：人工核对公开目录、中文选枪/配件UI、配装存取、截图三模式。

V0.3：完整状态快照门禁、精确Context曲线选择、16种合成场景、固定ROI参考图候选比较、状态实验室。不是实时游戏自动化或驱动完成。

V0.4：离线多尺度HUD候选、边缘/中心锚定、连续帧确认、参考包导入导出、原图拖拽框选与尺寸自动读取。没有实时采集或预训练游戏模型。

下一阶段：录像自动读时间戳与抽帧、真实HUD不同会话样本验收、停止延迟和误放行测量；原校准闭环接入GUI；未知目录项核验。禁止用单帧高相似度冒充准确率、用相同图片作独立验证。

最后：明确授权环境中的实时采集和驱动适配。Razer型号/版本最后确认，不阻塞核心开发；输入后端变化重做Response。
