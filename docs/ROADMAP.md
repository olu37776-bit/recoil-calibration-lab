# 路线图

V0.1：离线校准契约、Response、分段Profile、迭代、独立验证、RecordingSink、录像光流。

V0.2：人工核对公开目录、中文选枪/配件UI、配装存取、截图三模式。

V0.3：完整状态快照门禁、精确Context曲线选择、16种合成场景、固定ROI参考图候选比较、状态实验室。不是实时游戏自动化或驱动完成。

V0.4：离线多尺度HUD候选、边缘/中心锚定、连续帧确认、参考包导入导出、原图拖拽框选与尺寸自动读取。没有实时采集或预训练游戏模型。

下一阶段：录像自动读时间戳与抽帧、真实HUD不同会话样本验收、停止延迟和误放行测量；原校准闭环接入GUI；未知目录项核验。禁止用单帧高相似度冒充准确率、用相同图片作独立验证。

最后：明确授权环境中的实时采集和驱动适配。Razer型号/版本最后确认，不阻塞核心开发；输入后端变化重做Response。

V0.5产品候选：统一工作台、用户目录持久化、GUI校准闭环、Windows前台采集/标准输入适配、手动监督模式、打包自检。成熟的自动游戏识别与用户实机验收仍是独立缺口，不能由合成演示替代。

V0.6：手动负重标签和脚架选项、配装复制、个人参考截图库、独立识别检查、窗口实时识别与已验证曲线自动选档；所有活动在同一工作台。不推断不可见条件，不宣称全场景游戏通过。下一阶段优先用户实机误识别样本/键位兼容/采集延迟反馈，不再把重量公式或全枪预训练作为前置条件。

V0.7：日常首页、引导下一步、纯计算自动衔接、跨重启本机偏好、复制/自动命名及明确回退。下一步以用户第一次试用中实际卡住的步骤排序；仍未实现自动连续采样和成熟游戏识别。

V0.8：未补偿训练成组采集、失败保留成功轮次并补缺失、只读准备检查、倒计时与可选提示音、无图片诊断、窗口切换使预览失效。没有自动开枪、批量实际输出或无条件后台恢复。后续优先真实用户阻塞，不以更多配置字段替代可用性。
