# V0.7 可用性收口

基线：e4488a5fffcca7bf435eddba85729afb1767d994。用户要求从实际使用和调教角度减少操作，不继续增加孤立实验页面。

## 三个使用场景

1. 日常使用：选择已有配置/个人识别库、目标窗口和手动负重；清楚看到当前状态，明确开始或停止。记住上次选择，不恢复授权、不自动启动输出。
2. 第一次调教：选择配装，核对一次本机设置；按当前进度只推荐一个下一步。程序保存记录并计算进度，不要求用户理解response/fit、JSON或会话ID。
3. 效果不对：允许复制当前配装只修改一项；从原入口追加试射、检查新版、回到已有通过版本。未经验证的新结果不能覆盖已通过状态。

## 本轮优先实现

在现有workbench中增加日常入口和逐步提示；保留原控件和高级入口、现有存储/API及所有执行门禁。校准计划根据当前配置和当前曲线的记录计算，不将旧曲线验证次数算作新曲线完成。
常用设置仅在用户核对后保存；记住项目不代表认定当前游戏配置相同。窗口变化须核对，不默认勾选授权。首次设置自动命名可编辑，负重仍是手动标签。
识别会话ID由程序提供初始值并隐藏在高级信息中，同一录制的截图保持同一ID；新会话按钮不能把同图变独立。先识别观察，再明确应用。用户媒体不得进入仓库或源码制品。

## 验收

新安装有明确第一步；已有配置可恢复选择但输出关闭。清楚区分未调教、待检查、模拟演示、可受控使用。进度不足给出原因与下一步，不隐藏原始错误。复制不改旧配置；不重复计算旧验证；未知识别不应用。
复用现有测试并增加进度决策单测和真实浏览器操作测试。Windows便携包与提交绑定，发布仍需原门禁。用户实机/游戏/驱动验收不能由自动化测试代替。

## 不在本轮冒称完成

无人监督、全自动学习所有枪械、隐藏配件识别、无采集数据的参数估计、自动持续试射、实时强度滑块无需重验、完整识别批量标注。后续以用户实测阻塞排序，不扩大参数种类。

## 源码分发

增加只打包Git已跟踪文件的Source Bundle工作流，便于取回当前准确版本审查和给出源码下载；不打包运行目录、用户数据或凭据。该制品不代表功能验收。
