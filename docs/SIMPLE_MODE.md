# 简易手动调教版 1.2 RC1

基线 348a430b8b98bd6ae4713b66af959537c154fa49。用户实测旧版捕获超过50ms并指出呼吸干扰，要求简单可用。独立入口 RecoilLab-Simple.exe / python -m recoil_lab.simple_app。

## 使用
选配装和手动负重，先用默认20力度和2秒短连射试调。20只是低速测试起点，不是枪械实测配置。向上飘点+5，压过头点-5；满意后保存。窗口大小自动读取，不填DPI或游戏分辨率，不要求响应/训练/验证多轮采集，不装雷云。操作是在明确允许的受控环境中手动试调，不是自动校准或全游戏自动识别。

选择目标窗口并明确确认后，5秒内切回，先松开左键，再按住F7+右键+左键。松开即停；F8/Esc急停。每轮0.5～6秒，不循环；会话最长120秒。切窗、换弹/切枪/姿态指令、窗口变化、调度异常或界面心跳超时会停止，需要手动重新开始。程序不知道弹量，空仓应松开左键。修改参数或打开截图反馈都会停止输入。

截图反馈是可选：导入或粘贴一张原始弹着截图，先点墙上原来瞄准的地点，再点可见弹孔。只统计原图像素的静态偏移。不是自动弹孔检测，不从单张图生成时间曲线，不声称剔除呼吸或散布。图片只在内存，不自动保存或上传。

## 1.2 松手调节

继续只完善简易手动入口，不需要录屏、DPI或图像响应校准。实施范围与验收见 SIMPLE_12_PLAN.md。本版本不改main旧自动校准流程。

在主界面勾选“松手后用 F5 / F6 调节（可选）”，选择步长1、5或10，再按原方式选择窗口、确认、开始。**先松开 F7、鼠标左右键和F5/F6**，然后 F5 减小、F6 增大当前力度；按住不会重复累计。新力度同步回主界面的未保存草稿、撤销历史后，松开全部按键，再主动用 F7+右键+左键试射。

开火、开镜或按着F7时按F5/F6，会暂停本梭并拒绝调节，不会偷偷排队。两键同时按、启动前已按住的快捷键、陈旧应答不会修改参数。修改没有延长原120秒会话；普通按钮调节、换弹或切枪等仍按原规则停止。要长期保留仍需回主界面“保存这套”，手动保存不等于验证通过。

“显示状态小窗”是普通可移动置顶窗口，显示配装、力度与启停提示。不读取、不覆盖游戏内部界面；独占全屏可能看不到。打开/关闭小窗会停止当前输出，准备好后再点开始。快捷键可能与游戏本身的F5/F6绑定冲突，本程序不吞键，出现冲突可取消该选项。功能默认关闭且不保存输入许可。

实际输入沿用原标准Windows接口和所有限幅、时间、焦点、释放与急停检查。没有自动识别、自动弹痕检测、呼吸消除、自动点击或反作弊绕过。真实电脑/实体鼠标/游戏效果仍未验收。
