# 简易手动调教版 1.0 RC1

基线 348a430b8b98bd6ae4713b66af959537c154fa49。用户实测旧版捕获超过50ms并指出呼吸干扰，要求简单可用。独立入口 RecoilLab-Simple.exe / python -m recoil_lab.simple_app。

## 使用
选配装和手动负重，先用默认20力度和2秒短连射试调。20只是低速测试起点，不是枪械实测配置。向上飘点+5，压过头点-5；满意后保存。窗口大小自动读取，不填DPI或游戏分辨率，不要求响应/训练/验证多轮采集，不装雷云。操作是在明确允许的受控环境中手动试调，不是自动校准或全游戏自动识别。

选择目标窗口并明确确认后，5秒内切回，先松开左键，再按住F7+右键+左键。松开即停；F8/Esc急停。每轮0.5～6秒，不循环；会话最长120秒。切窗、换弹/切枪/姿态指令、窗口变化、调度异常或界面心跳超时会停止，需要手动重新开始。程序不知道弹量，空仓应松开左键。修改参数或打开截图反馈都会停止输入。

截图反馈是可选：导入或粘贴一张原始弹着截图，先点墙上原来瞄准的地点，再点可见弹孔。只统计原图像素的静态偏移。不是自动弹孔检测，不从单张图生成时间曲线，不声称剔除呼吸或散布。图片只在内存，不自动保存或上传。

## 新操作边界
精确新增范围：src/recoil_lab/simple_*.py，tests/test_simple_core.py，tools/run_simple.py，tools/build_simple.py，.github/workflows/simple.yml，docs/SIMPLE_MODE.md。打包时从原公开事实目录生成JSON，不编造武器参数。
这是独立的manual-user-v1手动参数路径；不是把旧Profile改成验证通过。原V0.8代码、门禁、项目与识别库不修改，原自动执行仍要求原验证。手动保存永远标game_verified=false，不获得自动识别执行权。
手动入口允许用户显式确认的限时标准输入试用；每次≤32counts、仅垂直、不自动点击，不读进程内存、不绕过反作弊。停止与发送共用锁，停止返回后不可再发送。条件改变不热切曲线，重新确认后试用。开始前在目标成为前台时绑定实际尺寸，执行中尺寸改变停止。力度0～400counts/s，累计量化避免小数截断。

配置单独存放在%LOCALAPPDATA%/RecoilLabSimple，不污染或迁移旧校准数据。只保存手动条件/力度/时长和最多50个历史版本，不保存使能、窗口或许可。未签名，不要求关闭防护或提权。

## 验证
原全部回归与新增状态机/边界/停止/存取/隐私检查必须通过。Windows及Linux原生Tk自检检查保存、回退、配装兼容、负重、2K截图标注和重启默认关闭。Windows runner打包真正单文件EXE，并运行这个EXE的原生窗口自检后才发布。测试不发送真实鼠标事件，不证明实体鼠标或游戏接受输入。真实用户效果尚需试用，不以自动测试代替。
