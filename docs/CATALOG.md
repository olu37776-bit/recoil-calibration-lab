# 公开目录与配装契约

目录以 `src/recoil_lab/catalog.py` 为单一数据源，`public_catalog()` 返回可展示 JSON。`build_preset()` 服务端校验全部选项，界面没有独立的兼容表。

## 来源与边界

人工核对日期2026-09-23，来源为独立社区资料站，不是官方承诺。每把枪保留逐枪来源 URL；每个配件保留配件数据页；兼容关系由逐枪页面确认。弹药来源包含逐枪清单与进度表。

目录只摘录选装需要的事实字段，不复制图片、描述文案、布局或整站数据库，不提供爬虫。来源站点的版本标签不可填作游戏版本。中文名称是界面译名，可能与游戏本地化不同。

14把武器、49个配件、18种弹药属于当前子集，不宣称全覆盖。A-91、M17S和KH-2002部分槽位为 partial-pending：源站标为推断的兼容不当成确认兼容。空列表表示本目录未确认，不是游戏中不可能安装。未知价格、解锁条件和包装数量保留null。

## 配装语义

武器ID、按固定槽位顺序排列的配件ID、弹药ID、实际倍率、姿态、脚架展开状态、分辨率、灵敏度、DPI、FOV、游戏构建号、目录revision与输入后端构成Context。改变任何条件，原校准不自动继承。

同一配装导入不信任旧context_id和calibration_status；服务端重新生成并标为UNMEASURED。握把与脚架共用underbarrel；弹匣必选，弹药口径必须匹配。

价格汇总只加枪体、一个弹匣和所选配件，未知项另列；不含弹药、库存数量和其他装备。解锁费与购买价分开展示。

面板修正只逐项显示。本版没有验证加法/乘法叠加规则，不显示伪精确总后坐力，也不将公开数字写入Response或Profile。

## 扩充验收

新增条目需明确稳定ID、来源、核对日期、槽位、名称和未知字段；新增兼容关系需逐枪证据。不凭相同口径推断枪口适配，不凭通用导轨推断全部瞄具适配。更改目录revision后重新生成配装指纹。
