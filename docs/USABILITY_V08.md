# V0.8 操作计划：少切屏、失败可恢复

基线 main：3d5625a7b77a47f17dc4302e72b594b546e9a3c8。沿用 AGENTS.md WRITE_SCOPE。

用户要求继续从使用与调教角度减少操作。本轮只推进：
1. 开始前只读检查：给出缺少哪项和去哪里处理，不发送输入、不认定游戏已许可。
2. 未补偿训练可显式启动一组最多3轮：不自动点击、不发送移动；每轮由用户重新释放并按下启动。响应与验证仍逐轮启动，不批量恢复实际输入授权。已成功的轮次立即保存；失败只停止当前组，用户确认后再补缺失轮次。
3. 清楚显示倒计时、组内进度和失败处理；导出不含图片、窗口标题、文件路径和账号的诊断摘要，不自动上传。
4. 切换窗口或项目使预览选区失效，避免用旧窗口选区；不修改已有配置与校准结果。

同组训练共享原始会话编号，各轮有不同 run_id，不把同组切片伪装独立验证。恢复操作重新核对窗口、授权、选区；不自动重试、不削弱时钟/观察/执行门禁。负重仍只手动选项。

验证：批次边界、无输入后端防护、释放重按、换弹仅在轮间等待、失败保留已保存数据、诊断白名单、预览失效、原有全部回归、真实浏览器和Windows打包自检。合成/模拟测试不等于游戏和鼠标实机验证。完成后更新CURRENT/QUICKSTART与证据，不用上轮PASS代表新HEAD。

## 已实现与限制

训练分组在NativeSession中独立为train_batch模式，NoMotionDesktop硬拒绝move，即使回归误传曲线也不能发送输入。响应、验证和执行不能以count>1启动。每轮等待期间动作只暂停准备；试射中动作仍按原规则中断。只有未补偿训练可以不返回工作台继续下一轮。
捕获和光流的原始时间/质量门禁没有放宽。单轮成功后保存，失败不删历史；最多3轮且总等待上限120秒，用户须重新触发每轮。可选系统音不作为成功证据。
客户端窗口变化清预览，并检查异步预览所属项目和窗口。前置检查只读，不能替代原生启动检查。诊断采用白名单，不包含原始异常文本。
