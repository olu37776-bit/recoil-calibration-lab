# Simple 1.4：单键开关与调好后的日常使用

基线：feature/simple-manual-20260923 @ a552fe662435a559bbe8a23865d6b413bf9b3a06。
用户明确要求可自行设置一个键、按一次启用/关闭，取消5秒准备，并询问保存后如何使用；报告旧版完全无效果。

## 明确改变的行为
- 新默认是单键开关，不是旧的按住F7监督模式。可选常见F键、Insert/Home/End和鼠标侧键。F8/Esc保留关闭，F5/F6为可选微调保留。
- 点击准备只开始监听、绝不产生输入。没有倒计时；用户到明确选择的前台窗口按启停键才开启，再按即关闭。按住不连翻。重启、修改配置不恢复开启状态。
- 单次用户授权的监听可持续到退出，不再120秒自动结束；实际单次输出仍受手动配置的0.5～6秒长度、0～400counts/s、每次32counts限制，不自动开火、不补发积压。
- 默认物理右键+左键触发；可明确选择仅左键以支持游戏切换式开镜。后者不检测是否开镜，腰射也会触发，UI必须明确提示。不得声称识别游戏开镜/弹量。
- R仅暂停当前一梭；松手后新按开火才继续，不猜换弹何时完成。切窗口、背包/切枪/姿态命令、F8/Esc关闭开关但保留监听，重新启用须主动按键。PID/尺寸变化、系统拒绝、线程/界面异常停止。
- 状态区区分监听、开启、等待按键、到达单次时长、输入已送入Windows、系统拒绝。显示物理按键和本次SendInput计数；送入Windows不等于游戏接受。提供只读按键诊断，不生成鼠标输入。
- 保存后给出日常使用入口；已保存用户打开直接进入日常页。可以回调教改值，输入许可与窗口不持久化。旧手动参数无需迁移。
