# Windows候选版使用

## 便携包
从本仓库提交绑定的prerelease取得RecoilLab-0.5.0-rc1-Windows-x64.zip，核对同页SHA256。解压整个文件夹、双击RecoilLab.exe，不需要Python，不要单独搬走EXE。默认打开本机浏览器，不输出鼠标移动。没有签名证书；被系统拦截时保留错误，不关闭保护或提权绕过。

## 首次自检
点击“一键跑完整演示”。看到SIMULATED_REPLAY、11条记录和2个版本，说明合成工作流跑通，不证明游戏压枪有效。导出、关闭后重新打开，项目仍保存。

## 真实受控采集
1. 创建实际配装、姿态、DPI、灵敏度、倍率、FOV和游戏版本项目。Windows标准后端不复用旧recording-only响应。
2. 在“采集与导入”读取窗口列表。窗口尺寸必须与项目一致，不同则新建正确项目。
3. 勾选授权、点击5秒后读取窗口预览，切到目标窗口。返回工作台，在预览拖框选择静态有纹理墙面，不框枪、准星、HUD或动态背景。
4. 采集响应：5秒内切回目标，按住F7+右键，不开枪、不移动鼠标。程序发送小幅上下测试输入。至少2轮。
5. 采集训练：按住F7+右键，先释放左键再按住左键完整开火，不手动压枪、不移动人物。至少3轮，每轮回到相同条件。
6. 自动标定响应，再生成曲线；门禁拒绝时按具体错误重新采集，不填假值。
7. 采集验证：在相同受控条件有限执行候选并测残余。需要3轮新采集会话，然后点击独立验证。
8. 只有RECORDED_REPLAY且门禁通过，才允许手动监督运行。改进时用新训练小步修正，并重新采集独立验证；旧版本可回退。

F7为额外使能，不是游戏状态识别；F8/Esc停止。换弹/投掷/切换/常见姿态键也中断。常规任务最长120秒，单条曲线最长6秒，按住不循环。响应采集不自动开枪。切枪、配件、姿态、灵敏度或分辨率后先停用并重建/选择项目。目前不支持按住Ctrl的蹲姿采集，因为Ctrl被保守地当成中断信号。

## 明确限制
不自动知道实际枪械/姿态/剩余弹量，不附带真实游戏预设曲线。Windows输入可能被目标拒绝，不绕过。背景跟踪测视角位移，不等同命中率。全屏/遮挡/显示缩放异常会拒绝，不暗中缩放。跟踪太慢超过时间门禁时保留错误，不生成虚假成功。

本机数据：%LOCALAPPDATA%\RecoilCalibrationLab；启动失败写startup-error.txt。原始游戏图像默认不存盘、不上传。主动导出的数值证据也可能含配装信息，请确认后再分享，不提交公开仓库。

## 源码启动
```
py -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[ui,video]"
.\.venv\Scripts\python -m recoil_lab.app
```
