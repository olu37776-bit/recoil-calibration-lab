# V0.7 先这样用

解压完整便携包，双击RecoilLab.exe，不单独搬走EXE。默认无输入。
第一次：点“调教配置”，选枪和配件、手动负重；展开“本机设置”核对并确认。保存后按调教助手提示操作。记录够一组后可自动计算，但每轮采集仍由你明确开始。
以后：直接在“开始使用”选配置，核对窗口、负重和识别库。先用“只看识别结果”，再在获准场景明确启用。
换配件或姿态：点“复制配置，只改一项”，修改后存新配置，旧结果不动。效果不对：看检查报告、追加试射、验证新版，或恢复明确的此前通过版本。
设置、上次配置和识别库保存于本机用户目录；不会记住授权和运行中的窗口。技术选项在“展开全部工具”。

# Windows候选版使用

## 便携包
从本仓库提交绑定的prerelease取得RecoilLab-0.6.0-rc1-Windows-x64.zip，核对同页SHA256。解压整个文件夹、双击RecoilLab.exe，不需要Python，不要单独搬走EXE。默认打开本机浏览器，不输出鼠标移动。没有签名证书；被系统拦截时保留错误，不关闭保护或提权绕过。

## 首次自检
点击“一键跑完整演示”。看到SIMULATED_REPLAY、11条记录和2个版本，说明合成工作流跑通，不证明游戏压枪有效。导出、关闭后重新打开，项目仍保存。

## 真实受控采集
1. 创建实际配装、姿态、DPI、灵敏度、倍率、FOV和游戏版本项目。Windows标准后端不复用旧recording-only响应。
2. 在“采集与导入”读取窗口列表。窗口尺寸必须与项目一致，不同则新建正确项目。
3. 勾选授权、点击5秒后读取窗口预览，切到目标窗口。返回工作台，在预览拖框选择静态有纹理墙面，不框枪、准星、HUD或动态背景。
4. 采集响应：5秒内切回目标，按住F7+右键，不开枪、不移动鼠标。程序发送小幅上下测试输入。至少2轮。
5. 采集训练：按住F7+右键，先释放左键再按住左键完整开火，不手动压枪、不移动人物。至少3轮，每轮回到相同条件。
6. 自动标定响应，再生成曲线；门禁拒绝时按具体错误重新采集，不填假值。
7. 采集验证：在相同受控条件有限执行候选并测残余。需要3轮新采集会话，然后点击独立验证。
8. 只有RECORDED_REPLAY且门禁通过，才允许手动监督运行。改进时用新训练小步修正，并重新采集独立验证；旧版本可回退。

F7为额外使能，不是游戏状态识别；F8/Esc停止。换弹/投掷/切换/常见姿态键也中断。常规任务最长120秒，单条曲线最长6秒，按住不循环。响应采集不自动开枪。切枪、配件、姿态、灵敏度或分辨率后先停用并重建/选择项目。目前不支持按住Ctrl的蹲姿采集，因为Ctrl被保守地当成中断信号。

## 明确限制
不自动知道实际枪械/姿态/剩余弹量，不附带真实游戏预设曲线。Windows输入可能被目标拒绝，不绕过。背景跟踪测视角位移，不等同命中率。全屏/遮挡/显示缩放异常会拒绝，不暗中缩放。跟踪太慢超过时间门禁时保留错误，不生成虚假成功。

本机数据：%LOCALAPPDATA%\RecoilCalibrationLab；启动失败写startup-error.txt。原始游戏图像默认不存盘、不上传。主动导出的数值证据也可能含配装信息，请确认后再分享，不提交公开仓库。

## V0.6 教识别与自动选档
先用第01至04页完成每套配置的校准。负重仅手動标签，不自动改曲线。已有项目可“复制配装到表单”，改姿态/负重等条件后创建新项目。

第05页：选择项目→导入PNG/JPEG/WebP原始截图或用刚才窗口预览→首次框1至3块可见图标→填本次采集会话→同意本机存裁剪→加入参考。切换左侧项目后添加对应状态截图。不要将相同录屏的截帧分别伪装成参考和独立验证。

每个配置再采集2张独立验证截图，每个负重标签加1张菜单/换弹/空仓等“应停止”负例。点击“检查整个识别库”；失败先改参考区域或补充样本，不能手动设为通过。单张弹着截图不能代替原先的时间曲线校准。

选本次负重与目标窗口，先用“仅识别”看匹配结果；确认后，在允许场景启用“识别并应用已验证配置”。F7+右键+左键仍是使能，不自动开枪。动作或识别变化暂停，稳定确认后先释放左键再开火。不会从画面推测不可见的负重/配件，不支持所有自定义动作键位，需持续监督。
