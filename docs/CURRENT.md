# CURRENT · V0.8.0-rc1

基线 main：3d5625a7b77a47f17dc4302e72b594b546e9a3c8。仓库 olu37776-bit/recoil-calibration-lab。

## 本轮交付

1. 调教中的未补偿训练默认提供“一次准备，补齐这一组”，最多3轮，整组等待上限120秒。每轮仍由用户松开F7和鼠标左右键，再主动试射；绝不自动点击或发送移动。单轮入口保留。
2. 各轮成功即保存。中途失败/用户停止，已成功记录保留；界面按当前项目已有记录计算需要补的轮次，不自动重试。组内共用原始会话ID，各轮有不同run_id；不能将同组训练冒充独立验证。
3. 开始条件只读检查，列出缺少的项目、授权、窗口或选区。检查不采图、不发输入、不授权后续执行。开始时仍重新核对。
4. 倒计时、已保存轮数、分类错误和下一步建议；可选每轮成功系统提示音。静音/声音失败不伪造记录，也不影响试射检查。
5. 用户主动导出无图片诊断：仅版本/系统/阶段/数量/固定错误分类；不包含原始错误、路径、窗口标题、账号、曲线或截图，不上传。
6. 修复高级窗口选择被日常下拉旧值覆盖的问题。切换/刷新窗口或切换项目会清除旧预览选区；预览异步返回必须匹配当前项目与窗口。读取列表后不默认选第一项。

响应采集、带补偿候选验证与实际执行仍逐轮确认，不借批次恢复输入许可。鼠标后端、识别库、实际曲线门禁与历史项目不变。
