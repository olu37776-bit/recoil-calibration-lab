# CURRENT · V0.7.0-rc1

基线：ad770a02de4491d32805815ecffeca78688cfd0a（UX源文件暂存已取回并核对，运行代码此前仍为V0.6）。仓库：olu37776-bit/recoil-calibration-lab。用户要求方便使用和调教，不扩大控制参数或削弱保护。

## 这次改动

同一工作台默认进入“开始使用”；“调教配置”“教它识别”分开，原全部工具折叠保留。日常页集中配置、目标窗口、手动负重、识别库、状态、开始与停止。读窗口和所有实际输入仍通过原有后端，不自动恢复授权或窗口句柄。

调教助手按已保存记录提示下一步，说明要按什么和是否开火；记录够一组后可自动计算标定、生成曲线或检查结果，只计算，不自动开始下一轮输入。进度区分当前候选验证与旧候选；失败不循环自动重试。

本机设置首次核对后保存至用户目录，跨随机端口/程序重启可复用。恢复上次配置、识别库不启用输出。配置可自动命名；复制只改所需字段，不修改旧项目。会话编号自动生成并保留同次录制语义，不能把更换编号当独立采集。

技术JSON、原始记录与长的配件解锁信息折叠，条件选项仍完整。可恢复明确的通过版本；多份通过版本且没有父链依据时，不猜“最近版本”，由用户在高级列表选择。

## 验证

以evidence/verification.json及源清单为本地证据。新增纯进度、候选隔离、偏好持久化与禁止保存授权单测；浏览器复用原完整演示/导出/识别测试并增加日常默认关闭、选择恢复、复制和设置复用。
本地浏览器网络导航被环境策略阻断，记录原始失败；DOM+本地服务桥接为另一个限定范围检查，不能替代远端真实HTTP浏览器。Windows/Linux、新EXE与发布必须按本轮提交重新通过原门禁。

## 仍有的产品边界

不是所有交互已一键化：实际每轮试射仍需用户按提示执行，识别参考仍需选区和独立样本；没有自动连续开火、免验证的力度滑块或成熟的全游戏识别。默认使能和急停方式未改变。用户电脑、WARDOGS、鼠标延迟和准确率未完成实机验收。
负重始终只是手动标签。未增加游戏内存读取、反作弊绕过、上传用户媒体或无授权输入。原V0.6识别与执行契约继续有效。

## 可复现检查

本轮完成暂存UX改动的源码核对，并移除一次性传输文件。`tools/smoke_product.py` 为真实HTTP浏览器流程；`tools/smoke_product_dom.py` 复用同一组操作但明确只做DOM/进程内桥接，不能覆盖前者的失败结果。
