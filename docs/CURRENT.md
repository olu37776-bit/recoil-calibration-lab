# CURRENT · V0.5.0-rc1

基线main：69acf43d4debcec62c3d3af97a1fe73076728189。仓库：olu37776-bit/recoil-calibration-lab。

统一工作台 /workbench.html：配装→本机项目→采集或Trial导入→响应标定→曲线拟合/小步迭代→独立验证→版本回退/导出。启动 python -m recoil_lab.app 自动选空闲端口、打开浏览器；数据保存用户目录，不存仓库。

新增Windows标准SendInput适配，不依赖雷蛇专有驱动。默认关闭，F7独立使能，右键+左键触发，F8/Esc急停；固定前台窗口/PID/尺寸、释放后重启、曲线末尾不循环、调度/网页心跳超时停止。原HUD候选仍没有自动执行权。至少2轮响应、3轮训练、3轮独立验证。有限候选验证和验证通过后的手动监督运行分开；合成曲线不能真实输出，模型预测不能充当实测回放。历史版本不覆盖。

不是成熟的全游戏自动识别成品：没有经过游戏验收的姿态/弹量/枪械模型，不自动读取游戏设置。按键中断是停止信号，不是完整游戏状态。标准输入可能被目标拒绝；不提权、不绕过。Windows硬件、WARDOGS实机和独立审查未完成。

以evidence/verification.json及源码指纹为准。核心回归、真实HTTP自检、受限环境DOM桥接分别记录。本机浏览器HTTP导航被ERR_BLOCKED_BY_ADMINISTRATOR阻止，故不宣称本机网络浏览器E2E通过；远端增加独立真实浏览器流程。
