# CURRENT · V0.6.0-rc1

基线 main：c944f62c10e730664fb8645778036a4fbb6b8b8e。仓库：olu37776-bit/recoil-calibration-lab。

本轮用户明确要求：自己选条件、截图/试射校准，之后自动识别并应用；负重仅做手动选项。

## 已实现
- 原有配装、响应/训练/独立回放验证、持久化项目、Windows标准输入适配保留。
- 工作台增加负重标签（未记录/轻装/中装/重装/自定义）、脚架展开、复制配装到新项目。负重只参与精确匹配，无默认后坐乘数。历史缺失负重的项目不改写。
- 第05页个人识别库：首图框1至3个区域，复用同库区域；将截图绑定项目。只在同意后保存归一化的灰度裁剪，完整原图不存盘，不上传。
- 参考/独立验证分开；每配置2张验证图、每负重1张未知负例；同图、同参考采集会话拒绝。新样本使旧检查失效。
- 识别新截图后可自动选中项目；实时仅识别或自动选档。自动输出同时要求识别库验证与原RECORDED_REPLAY曲线验证通过，F7+右键+左键使能；窗口/PID/尺寸、急停、心跳和每轮时长限制保留。
- 识别未知、歧义、动作或切档暂停，连续确认后重新释放左键再开火，不在同一梭中换曲线；没有自动点击或无人监督模式。

详见SELF_TEACHING.md。此为用户教样本的识别器，不是预训练全枪全姿态模型。不推断隐藏配件、负重、设置；有限样本检查不是完整游戏准确率证明。原V0.3/V0.4通用候选接口仍不能直接输出。

## 验证
当前结果以evidence/verification.json及源码指纹为准。新增测试覆盖负重、存取、分类/歧义、独立截图检查、旧结果失效、输出前两重检查和连射切档/释放。浏览器新增负重填表、建立识别库、截图匹配和重启持久化流程。

本机浏览器HTTP导航受环境限制；该失败原样保留，不作为产品根因。远端Windows/Linux、浏览器真实HTTP和打包自检必须对本轮HEAD重新查询，成功后才发包。没有用户电脑或WARDOGS实测、没有独立审查结论。

## 使用边界
同一识别库要求原图分辨率和输入环境一致，不自动迁移旧曲线。需要用户选取运行时可见的稳定图标，不能拿只在背包里显示的内容当成持枪时一直可见。负重改变先停止，再手动选择对应标签。按住Ctrl/Shift仍是保守暂停条件；未宣称所有自定义键位兼容。
