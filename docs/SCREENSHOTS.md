# 截图输入契约

原始图片是本机用户显式提交的PNG/JPEG/WebP，禁止服务端按URL下载或按用户指定路径读取。无OCR、无自动弹孔识别、无游戏内目标检测。不得上传用户原图到公开仓库。

单图：用户标注初始瞄准点和可见弹孔，输出原始像素坐标、标注数、质心、边界和RMS。重叠弹孔无法恢复发数；无时间语义，`can_fit_time_curve=false`。

双图：相同尺寸及配装分辨率，静态ROI光流双向验证、至少12匹配内点、质量至少0.65、平移残差不超过1.25像素。输出背景反向相机总位移。大位移、场景变化和低纹理会拒绝。通过质量门禁也不能排除主动视角转动，不证明位移全是后坐力。

序列：10～120张、显式有限非负时间戳、同尺寸、固定瞄准状态且无补偿；复用video.track_frames，不改变至少0.2秒、间隔最多0.1秒、质量0.65等Trial门禁。不按文件名或EXIF猜测时间。输出train阶段Trial的JSON和CSV，不宣称是验证回放。

`capture_session`是用户声明的原始录制组ID；同一录像的裁剪片段必须相同。保存每帧字节hash和frame_set_sha256作为来源证据；capture_sha256在此适配器中兼容旧核心字段，承载声明的采集组ID而非声称其本身为SHA-256。

单图最大6MiB/1200万像素；HTTP请求最大32MiB；序列总解码像素最多9000万。画布缩放不改变原图坐标；与Context分辨率不符则拒绝，不静默缩放。RGB转换不自动旋转EXIF，不处理动图。

截图时间线不能替代输入日志；未实际测得像素/输入单位Response时，不能输出可信鼠标补偿单位。界面只导出测量，拟合/迭代仍通过原CLI执行。
